The point is to decide which scenic format should stay as the default while the channel is still small.

## Side-By-Side Review

### Ocean Drift Strengths

- cleaner visual identity for a calm sleep channel
- easier to recognize as a scenic ambient format at a glance
- softer branding fit for `Midnight Tide Sleep`
- simpler default for broad scenic uploads

### Rain Window Strengths

- stronger niche crossover with brown-noise intent
- more specific mood packaging
- good secondary format for follow-up uploads

## Current Decision

Keep `ocean-drift` as the default scenic preset.

Why:

- it is the broadest scenic fit for the channel identity
- it keeps the visual system cleaner while the channel is still establishing itself
- `rain-window` is still valuable, but reads better as a secondary themed variation than as the default house style

## What Changes From This Decision

- `launch-02` remains the default publish-ready scenic concept
- `rain-window` stays in rotation as a follow-up format
- future scenic uploads should start from `ocean-drift` unless a specific theme calls for rain-window
